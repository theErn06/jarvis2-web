User Guide

System Overview

Welcome to the Jarvis Smart Fridge dashboard. This application synchronizes directly with your local smart refrigerator hardware, allowing you to monitor your groceries and track food waste from anywhere.

How to Connect to Jarvis

  • 1️⃣

    Open the Jarvis Interface

    Open the sidebar menu (☰) and click or tap the 🤖 Jarvis icon at the bottom of the navigation list.

  • 2️⃣

    Find the IP Address

    If you are accessing the dashboard from your phone, a prompt will ask for an IP address. Look directly at your physical fridge's Arduino LCD Display. It will show an IP address (e.g., 192.168.1.10). Type this exact sequence of numbers into the prompt.

  • 3️⃣

    Return to the Dashboard

    When you are finished chatting with Jarvis, simply tap the red "← Go Back" button at the top left of the screen. This will safely close the secure direct connection and instantly return you to the main dashboard.

Jarvis Chat Controls

  • 🎙️

    Voice Commands

    Tap the green microphone icon to activate voice recognition. The icon will pulse red while listening. Speak naturally (e.g., "Add two apples").

  • ⌨️

    Text Commands

    If you are in a noisy environment, you can type your command directly into the input bar and press the blue Send arrow.

Hardware Status

  • 🚪

    Smart Door Sensor

    A physical sensor tracks when the fridge door is opened or closed. If the door is left open for more than 30 seconds, Jarvis will audibly warn you to close the fridge to save energy.
